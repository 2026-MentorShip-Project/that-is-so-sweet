## Why

AI 推薦偏好表單的其他料理與忌口／過敏「＋加入」輸入列，在手機寬度下被輸入框預設最小寬度撐開，出現橫向捲動。

## What Changes

- 共用 ChipInput 改用 minmax(0, 1fr) 與 auto 兩欄，輸入框可縮到剩餘空間，「加入」按鈕維持完整可見。
- Design-system Input 的容器與原生 input 允許縮小，避免預設 intrinsic width 撐開 flex 排版。
- 已加入的料理與過敏標籤限制在容器寬度內，長文字可換行，移除按鈕不被壓縮。

- 實測 320px 時底部兩個操作按鈕也會溢出；改為窄螢幕自動換列，寬螢幕維持同列。

## Scenarios

- 在 320、360、375、390、430px 手機寬度，兩個輸入列與加入按鈕均不超出表單寬度。
- 加入較長且無空白的料理／過敏文字時，標籤換行且仍可移除，不造成橫向捲動。
- 桌面版維持輸入框與加入按鈕同列，既有新增、Enter、移除與項目數限制維持。
